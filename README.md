A NestJS and MySQL API organized around business capabilities such as authentication, catalog, contracting, finance, and teams.

### [Stock Management Frontend](https://github.com/ELMOURTAZAKS/gestion_stock_front)

An inventory interface that explores how a web client handles stock-management workflows through an API.

### [Nexus Browser](https://github.com/ELMOURTAZAKS/nexus)

A Java and JavaFX desktop browser that explores embedded Chromium, multi-tab workflows, and persistent user data with SQLite.

## How I work

I start with the user need and likely failure cases, then define the API contracts and data ownership. I build and test the feature, verify that the components work together, and use logs, metrics, and traces after deployment to guide the next change.

<details>
<summary>How I think about requests in a distributed system</summary>

A client sends a request to an API gateway, which routes it and applies policies such as authentication. Service discovery supplies the available instances, and a load balancer selects an eligible instance. The service can read or write data and publish an event. The response returns to the client while downstream work can continue asynchronously.

</details>
